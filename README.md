### アプリ名
Guruharu(グルハル)

#### コンセプト
「学生生活を豊かにする、グルメとの出会いアプリ」  
このアプリは、学生生活の中で出会うグルメを通じて、  
楽しみや、ちょっとした発見、青春の"きっかけ"を届けたいと考えました。  
名前の「Guruharu」は「グルメ×春(青春)」の意味を込めて名付けました。

#### こだわったポイント
- 飲食店の検索条件の中で、現在地だけでなく学校名や駅名から近くのレストランを検索できるようにしました。
- 2000円以上の検索条件をひとくくりにしました。

#### デザイン面でこだわったポイント
- 検索一覧をそれぞれカードにして表示することで分かりやすいデザインにしました。
- 詳細画面では写真一枚とテキスト情報のみだと画面が寂しかったのでマップを追加しました。
- 現在地を取得するときに、ユーザーに視覚的なわかりやすさを提供するために、ボタンのテキストを「取得中」に変化させたり、取得した後は学校名などを入力する欄に「現在地」と入るようにしました。
- イメージカラーにはオレンジを採用しました。食欲をそそりやすいような暖色系にすることを意識しました。また、グラデーションをかけることでリッチなデザインを演出しました。

### 開発環境構築手順(ウェブアプリ)

 - git clone https://github.com/mon-ina/guruharu.git
 - cd guruharu
- 必要なGemをインストール
 - bundle install
- .envファイルにAPIキーを設定
 - HOTPEPPER_API_KEY=your_key
- サーバーを起動
 - rails s

## アプリケーション機能
### 機能一覧
- レストラン検索
  - ホットペッパーグルメサーチAPIを使用して、現在地や指定した位置情報をもとに周辺の飲食店を検索できる。
 　 -※現状以下の場所からのみ検索可能(坪内総合ビジネスカレッジ,島根大学,島根県立大学松江キャンパス,島根県立大学浜田キャンパス,松江西高等学校,松江工業高等専門学校,松江駅,東京駅)
    - 範囲選択(1～5km)
    - ジャンル、予算、営業中のみ、で絞り込み可能
- レストラン詳細情報の表示
  - 選択した飲食店の詳細情報（店名,住所,アクセス,営業時間,予算,キャッチコピー,画像,地図）を表示。
- 条件変更機能
  - 検索画面以外にいるときにヘッダー上の検索バーで変更可能

### 画面一覧
- 検索画面 ：条件を指定してレストランを検索する。
- 一覧画面 ：検索結果の飲食店を一覧表示する。
- 詳細画面 ：飲食店の詳細情報を表示する・

### 技術面でアドバイスして欲しいポイント
- Bootstrapを使って見た目を整えましたが、ユーザーにとって「使いやすく、直感的に分かりやすいUI」を作るために、どんな工夫をすれば良いか知りたいです。
例えば、ボタンのデザインについて、色や形を統一していたため、異なる機能のボタンでも一見すると違いが分かりにくく、意図しない操作をしてしまう可能性があると感じました。
文字だけでなく「色」「アイコン」「位置」などで明確に区別したり、視線誘導を意識することで、よりユーザーに優しいデザインになると思うのですが、具体的な改善方法についてアドバイスをいただきたいです。
